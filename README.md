# IELTS Speaking Forecast T9–T12/2026

Trang web tĩnh (một file `index.html`, không cần build) chứa bài mẫu band 7+ cho Part 1, 2 và 3.

## Deploy

GitHub Actions (`.github/workflows/pages.yml`) tự deploy lên GitHub Pages mỗi khi push vào `main`.
Lần đầu: vào **Settings → Pages → Build and deployment → Source** và chọn **GitHub Actions**.

Trang cũng deploy được lên Netlify, Vercel hoặc Cloudflare Pages: trỏ thư mục publish về gốc repo, không cần lệnh build.
